# Unified Application Platform

A single platform that connects BuildPiper, REMS, and SpendSmart across the application lifecycle: delivery, operations, monitoring, and cost optimization.

```text
+----------------------+
| Application Team     |
+----------------------+
          |
          v
+----------------------+
| Unified Platform     |
| Application Context  |
+----------------------+
          |
          v
+----------------------+
| BuildPiper           |
| Build and Deploy     |
+----------------------+
          |
          v
+----------------------+
| Running Application  |
+----------------------+
        /       \
       v         v
+----------+  +------------+
| REMS     |  | SpendSmart |
| Health   |  | Cost       |
| Events   |  | Usage      |
| Alerts   |  | Optimize   |
+----------+  +------------+
       \         /
        v       v
+----------------------+
| One Application View |
| Deploy, Operate,     |
| Monitor, Optimize    |
+----------------------+
```

## Output

One connected view of every application:

> Build it with BuildPiper, operate it with REMS, understand its cost with SpendSmart, and manage everything through one unified platform.
